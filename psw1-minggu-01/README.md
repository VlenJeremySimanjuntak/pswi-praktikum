# HTML
HTML merupakan sebuah struktur penyusun terhadap elemen yang menjadi fondasi sebuah pengembangan situs website tanpa ada nya elemen yang menjadi desain untuk mempercantik sebuah website

# CSS
CSS adalah sebuah elemen penyusun desain meliputi warna, ukuran atau bahkan arah dari sebuah elemen mengarahkan nya kepada tag html

# Javascript
Javascript adalah sebuah bahasa pemrograman yang bisa dipakai untuk menambahkan interaksi pada tag html maupun css sebagai pendukung terhadap fitur transformasi data maupun transaksi data didalamnya
